This project is a single-page resume website built using **pure HTML only**, without any CSS or external libraries.
The purpose of this project is to demonstrate a clear understanding of HTML structure, semantic elements, lists, and tables while following the given layout requirements.

---

## 📌 Features

- Single-page resume layout
- Built using only HTML
- No CSS or JavaScript used
- Structured sections for easy readability

---

## 🧩 Sections Included

- Header / Name
- About Me
- Skills List
- Experience (Table)
- Projects
- Education (Table)
- Contact Details
